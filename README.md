### 👩‍💻 Sobre mí

Analista de Datos Junior y desarrolladora de software en formación, con conocimientos en desarrollo de aplicaciones, análisis de datos y gestión de bases de datos.

Trabajo con **Python**, **C#** y **Dart**, desarrollando aplicaciones de escritorio con C# y Windows Forms, aplicaciones web con Blazor, y aplicaciones móviles con Flutter. También cuento con conocimientos en HTML, CSS, JavaScript, Git y GitHub.

En el área de datos trabajo con SQL, MySQL, SQL Server, Excel, Power Query, Power Pivot, Power BI y DAX, aplicando procesos de limpieza, transformación, modelado, análisis y visualización de información.

Me interesa seguir aprendiendo y conectar el desarrollo de software con los datos, creando proyectos que me permitan convertir conocimientos en soluciones prácticas.

> *"Cada día hay algo nuevo por aprender; puedes quedarte donde estás o seguir avanzando."*
